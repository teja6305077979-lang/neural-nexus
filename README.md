# Resume Skill-Gap Assistant (GENAI-09)

An AI assistant that compares a candidate's resume with selected job descriptions, identifies relevant skill gaps, and explains areas for improvement with evidence-based recommendations—without making hiring decisions on behalf of employers.

---

## 🚀 How to Run the App (Super Easy!)

### Method 1: The 1-Click Double-Click Method
Just double-click the file named:
👉 `start_app.bat`

That's it! It will launch the app and open your browser automatically.

---

### Method 2: From PowerShell / Command Prompt
Open a terminal in this folder and run:
```bash
python -m streamlit run app.py
```

## 🛡️ Problem Statement Compliance & Guardrails

- **Strictly Educational**: Provides constructive skill alignment and personalized learning roadmaps.
- **No Hiring Decisions**: Explicitly prohibited from issuing hiring/rejection judgments or speaking on behalf of employers.
- **Evidence-Based**: Quotes direct snippets from both the uploaded Resume and the Job Description to justify every identified match or gap.
